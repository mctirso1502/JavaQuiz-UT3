# JavaQuiz-UT3

Aplicación de consola desarrollada en Java que plantea un cuestionario interactivo de 6 preguntas tipo test sobre programación en Java y contabiliza la puntuación final del usuario.

Práctica colaborativa de control de versiones con Git y GitHub para la asignatura de **Entornos de Desarrollo (1.º DAW - Curso 2026/2027)** en el **IES Isidra de Guzmán**[cite: 1].

## Integrantes y reparto de tareas
* **Mario Cabello Tirso** (`@mctirso1502`): Creación del repositorio, estructura base con `Scanner` y desarrollo de las preguntas 1, 2 y 3.
* **Darío Sierra Asenjo** (`@DarioSierra15`): Desarrollo de las preguntas 4, 5 y 6, y lógica del contador final de aciertos.

## Estructura del repositorio
* `JavaQuiz.java`: Código fuente principal con la lógica del cuestionario y las 6 preguntas.
* `README.md`: Documentación básica del proyecto.
* `.gitignore`: Archivos y carpetas excluidos del control de versiones.
